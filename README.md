# Ghost AI

Ghost AI is a real-time collaborative system design workspace. Describe a
system in plain English, and an AI agent maps it onto a shared canvas as you
and your team refine the architecture together — then turn the finished
diagram into a Markdown technical spec.

## What it does

- **Collaborative canvas** — a shared, real-time architecture diagram (nodes,
  edges, shapes, colors) built on Liveblocks and React Flow, with live
  cursors and presence for every collaborator in the room.
- **AI-powered architecture generation** — describe what you want to build in
  the AI sidebar's chat, and a Gemini-backed background agent turns your
  prompt into nodes and edges written directly into the shared canvas, with
  its own live cursor, presence, and a shared status feed so everyone in the
  room can see it work.
- **Starter templates** — import a prebuilt system design (microservices,
  event-driven, CI/CD pipeline, and more) to start from instead of a blank
  canvas.
- **AI-powered spec generation** — convert the current canvas graph and chat
  history into a Markdown technical specification, generated by another
  background AI task, persisted, and downloadable from the sidebar.
- **Projects & collaboration** — authenticated project creation and
  ownership, with per-project collaborator invites and access control.

## Stack

| Layer             | Technology              |
| ----------------- | ------------------------ |
| Framework         | Next.js 16 + TypeScript  |
| UI                | Tailwind CSS + shadcn/ui |
| Auth              | Clerk                    |
| Database          | Prisma + PostgreSQL      |
| Canvas            | Liveblocks + React Flow  |
| Background tasks  | Trigger.dev              |
| AI                | Gemini via the AI SDK    |
| Artifact storage  | Vercel Blob              |

## Getting started

Install dependencies and set up your environment:

```bash
npm install
```

Copy the required environment variables into `.env`/`.env.local` — you'll
need keys for Clerk, Liveblocks, Prisma Postgres, Vercel Blob, Trigger.dev,
and Google's Generative AI API (Gemini). See the existing `.env`/`.env.local`
files for the exact variable names this project expects.

Run the database migrations and start the dev server:

```bash
npx prisma migrate dev
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.

Background AI tasks (design and spec generation) run through Trigger.dev and
need its own dev process running alongside `next dev`:

```bash
npx trigger.dev@latest dev
```
